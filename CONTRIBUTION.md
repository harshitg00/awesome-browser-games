# Contributing Guidelines

Thank you for helping curate this list! To ensure this repository remains high-quality, easy to maintain, and clear for visitors, please follow these guidelines.

---

## ⚠️ Core Quality Rule
**Only submit games you have personally played and genuinely enjoyed.**  
Do not submit random links, SEO spam, or unverified browser games. This list is strictly for games worth sharing.

---

## Submission Criteria
1. **Playable In-Browser:** The game must run directly in modern web browsers without requiring downloads, external launchers, or browser extensions.
2. **Direct Playable Links:** Provide the full, explicit URL to the game (e.g., `https://www.nytimes.com/games/wordle`), not a shortened URL or affiliate link.
3. **Correct Categorization:** Place your game under the relevant section or sub-section table.

---

## Formatting Guidelines

All entries must be added as a new row in the appropriate Markdown table using the format below:

| Game Name | Direct Link | Description | Tags |
| :--- | :--- | :--- | :--- |
| **Game Name** | https://direct-game-url.com | Short 1-sentence description highlighting mechanics or gameplay. | `#tag1` `#tag2` |

### Formatting Rules:
- **Direct Link:** Put the raw URL directly (do not use Markdown hyperlink brackets).
- **Description:** Keep it concise (1 short sentence). Provide a description for every entry—do not leave the description blank.
- **Tags:** Use lowercase inline code tags like `` `#tag1` `#tag2` ``.
